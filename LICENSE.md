# FBT core libraries license information

Source code in this repository is covered by one of several different licenses.

Most of the first-party code is licensed under the terms of GPLv2 or later, with the exception of the `furi` library which is available under the MIT license.

Third-party libraries are available under their respective licenses, and some files might have explicit license headers (which take precedence over everything else).

For more details, see the [REUSE](REUSE.toml) file which fully describes which file is covered by any particular license. See https://reuse.software/ for more info on interpreting this file.
